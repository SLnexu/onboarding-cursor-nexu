Conectar Cursor al repo de Nexu

Guía para PMs. Al terminar vas a poder preguntarle al agente cómo funciona el producto y que te conteste leyendo el código real, sacar análisis y reportes, y consultar y crear tickets de Linear sin salir de la conversación.

No vas a programar ni a instalar el backend. No hace falta.

Necesitas tres cuentas: GitHub, Cursor y Linear. Cada sección está partida en "si ya la tienes" y "si no la tienes": lee solo tu rama.

1. GitHub

La invitación llega a tu correo de Nexu, así que lo único que tienes que asegurar es que ese correo esté en tu cuenta de GitHub.

Si ya tienes cuenta de GitHub

No crees otra. Agrega tu correo de Nexu a la que ya usas:

  1. Entra a github.com/settings/emails.
  2. En Add email address escribe tu correo de Nexu y dale Add.
  3. Abre el correo de verificación de GitHub y confirma.
  4. Revisa que tengas 2FA activado en github.com/settings/security. Si no lo tienes, actívalo con los pasos de abajo: sin 2FA no vas a poder aceptar la invitación.

Si no tienes cuenta de GitHub

  1. Entra a github.com/signup.
  2. Usa tu correo de Nexu, no uno personal. Ahí te va a llegar la invitación.
  3. Crea la contraseña y guárdala en el gestor de contraseñas de la empresa.
  4. Elige tu nombre de usuario. Es público y único en todo GitHub, así que usa algo profesional y reconocible (nombre-apellido). Vas a aparecer así en el repo.
  5. Activa la verificación en dos pasos en github.com/settings/security: Enable two-factor authentication → Authenticator app → escanea el código con tu app de autenticación (Google Authenticator, 1Password o la que uses).
  6. Guarda los códigos de recuperación que te muestra. Si pierdes el teléfono, son la única forma de recuperar tu cuenta.

Aceptar la invitación

Cuando llegue el correo de GitHub, ábrelo y acéptalo. Que te hayan invitado no basta; mientras no aceptes, no tienes acceso. Aquí se atora la mayoría.

Para comprobar que quedó, entra a github.com/prestemos/prestemos_backend: si ves el código y no un 404, estás dentro.

2. Cursor

Si ya tienes Cursor instalado

Sáltate la instalación y revisa dos cosas:

  • Que la app esté actualizada: menú Cursor → Check for Updates.
  • Con qué cuenta estás conectado: Cmd + Shift + J → General → Account. Tiene que ser tu correo de Nexu, no una cuenta personal.

Si no tienes Cursor

Necesitas macOS 12 (Monterey) o posterior.

  1. Entra a cursor.com/download y descarga la versión para Mac.
  2. Abre el archivo descargado y arrastra Cursor a la carpeta Applications.
  3. Abre Cursor desde Aplicaciones.
  4. La app te va a pedir iniciar sesión. Hazlo con tu correo de Nexu.

Opcional, solo si vienes de VS Code y quieres tus extensiones: Cmd + Shift + J → General → Account → botón Import en VS Code Import.

Unirte a la cuenta de Nexu

Te llega una invitación por correo desde el panel de Cursor: ábrela y acéptala. Si Nexu tiene activado el ingreso por dominio, puede que te unas automáticamente al iniciar sesión con tu correo de la empresa.

Si hoy pagas Cursor Pro por tu cuenta: al unirte al equipo, esa suscripción individual se cancela automáticamente. Es lo normal, pero mejor saberlo antes que después del cargo. Una cuenta solo puede pertenecer a un equipo a la vez.

Si Cursor no conecta por la VPN o el proxy de la empresa: Cmd + Shift + J → Network → cambia HTTP Compatibility Mode a HTTP/1.1.

3. Linear

Si ya usas Linear

Confirma que entras a linear.app con tu correo de Nexu y que ves los proyectos del equipo. Pasa a conectarlo con Cursor.

Si no usas Linear

La invitación al workspace también llega a tu correo de Nexu. Acéptala y entra a linear.app para definir tu acceso.

Conectar Linear con Cursor

Esto es lo que le permite al agente leer y crear tickets desde la conversación. Hazlo después de tener acceso a Linear, porque te va a pedir iniciar sesión. Es de un clic: no tienes que editar ningún archivo de configuración.

  1. Abre Cursor.
  2. En la barra lateral, entra a Customize.
  3. Haz clic en MCPs.
  4. Busca Linear en la lista.
  5. Dale Add to Cursor.
  6. Sigue los pasos de autenticación: se abre el navegador para que autorices el acceso con tu cuenta de Linear.

Para comprobar que quedó, abre un chat nuevo y revisa la lista de herramientas arriba del panel: deben aparecer las de Linear. Si algo falla, Cmd + Shift + U → MCP Logs muestra el error real; si de plano no conecta, quítalo desde Customize → MCPs y agrégalo otra vez.

La primera vez que el agente use una herramienta de Linear te va a pedir aprobación. Es normal: Cursor confirma antes de tocar algo fuera del editor.

Si prefieres, este paso lo hacemos juntos en la sesión.

4. Lo que hacemos en la sesión

Nada de esto lo tienes que preparar; es para que sepas a qué vas.

Descargar el repo. Copiamos el código a tu computadora. Toma unos minutos y necesitas alrededor de 500 MB libres. Lo dejamos configurado para que puedas leer, pero no publicar cambios.

Las dos formas de usarlo. Cursor tiene varios modos; a ti te importan dos, y se cambia entre ellos con Shift + Tab o con Cmd + .:

Modo Qué hace Cuándo lo usas
Ask Solo lee y responde. No modifica nada. Entender cómo funciona algo: "¿cómo se valida el comprobante de domicilio?"
Agent Lee, escribe archivos, corre comandos y usa Linear. Sacar un reporte, armar un análisis con datos, crear un ticket

Empieza en Ask: por diseño no cambia nada, así que puedes preguntar lo que sea sin miedo a romper algo.

Cuando pases a Agent, ten presentes las dos redes de seguridad: el botón Stop lo interrumpe a media tarea, y pasando el cursor sobre cualquier mensaje anterior aparece Restore Checkpoint, que revierte todo lo que hizo después de ese punto.

Además, el repo trae reglas propias que el agente respeta solo: los reportes se guardan en la carpeta que les toca, con el formato definido y la evidencia que dev necesita. No tienes que pedirlo.

Checklist para el día de la sesión

  • Cuenta de GitHub con mi correo de Nexu
  • 2FA activado en GitHub
  • Invitación al repo aceptada (veo el código, no un 404)
  • Cursor instalado y con sesión en la cuenta de Nexu
  • Invitación de Linear aceptada
  • ~500 MB libres en disco
  • Puedo instalar programas en mi computadora (permiso de administrador)

Si algo de esto no se pudo, avísame antes de la sesión. Casi todo depende de que alguien apruebe un acceso, y eso no se resuelve en el momento.
